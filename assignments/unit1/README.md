## 建立 Agent

1. 在 Coze 建立 `NCU Course Assistant Prototype`。
2. 貼入 [System Prompt](system_prompt.md)。
3. 依作業描述選用 GPT-4o mini；若平台未提供，記錄當日可用模型及替代選擇。
4. 查看 Gemini 官網的模型列表，記錄查詢日期與來源。
5. 比較 Coze 可用模型的費率與計費單位，找出適合本次練習的便宜模型。
