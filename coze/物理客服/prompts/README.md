# 中大物理教具社客服：Prompt 版本紀錄

Coze 的 Prompt Management 儲存時出現「System exception, please try again later」（2026-10-02），無法存入平台的 Prompt 資源庫，因此改用 Git 管理 prompt：每個版本存成一個檔案，每次修改都是一次 commit，可以比較差異、回到舊版。

| 版本 | 檔案 | 變更內容 | 測試結果 |
|---|---|---|---|
| v1 | `客服_v1.txt` | 完整客服 prompt：角色、語氣、商品、政策、規則、範例（XML 拆解） | 五題測試腳本全部符合規則 |
| v2 | `客服_v2_salted.txt` | 規則改用加鹽標籤 `<rules_x7k29>`，加入攻擊偵測規則與固定拒答句 | 三種注入攻擊皆以固定句拒答 |

用 Git 管理 prompt 的好處：
- **版本追蹤**：`git log` 看得到每次改了什麼、為什麼改。
- **回復**：新版出問題時，可以退回上一版。
- **重複使用**：其他 Agent 可以直接引用同一份檔案。
